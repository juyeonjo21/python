# ERP 문의 관리 시스템 (ERP Helpdesk)

## 프로젝트 개요
사내 직원이 ERP 문의·개선 요청을 등록하고, ERP 담당자가 답변·처리 과정을 관리하는 웹 시스템.
단순 게시판이 아니라 접수 → 담당자 지정 → 답변 → 처리 완료까지 이력을 관리하는 업무 시스템이다.

## 기술 스택
- Python 3.12, Django 5
- DB: 개발 SQLite (운영 시 PostgreSQL로 전환 예정)
- 화면: Django 템플릿 + Tailwind CSS(CDN) + HTMX(CDN) + Chart.js(CDN)
- 폰트: Pretendard (CDN)
- 설정값은 .env로 분리 (django-environ)

## 폴더 구조
- config/        프로젝트 설정
- accounts/      사용자·부서·권한
- inquiries/     문의·답변·이력·첨부 (핵심)
- notices/       공지사항
- notifications/ 이메일 발송·발송 기록
- dashboard/     통계
- templates/     공통 레이아웃·컴포넌트 (base.html, components/)
- static/        CSS·JS·이미지
- media/         업로드 파일 (git 제외)

## 사용자 역할
- USER(일반 사용자): 문의 등록, 본인 문의만 조회
- AGENT(ERP 담당자): 전체 문의 조회, 담당자 지정, 답변, 상태 변경
- ADMIN(관리자): 사용자·부서·카테고리·공지 관리, 통계, 설정

## 문의 상태
접수(RECEIVED) → 확인 중(CHECKING) → 처리 중(IN_PROGRESS) → 답변 완료(ANSWERED) → 처리 완료(CLOSED)
예외: 보류(ON_HOLD), 반려(REJECTED) — 사유 필수
문의번호 형식: ERP-YYYY-NNNN (예: ERP-2026-0001)

## 디자인 원칙 (Notion 스타일, 단 독자 UI)
- 미니멀, 넉넉한 여백, 얇은 테두리, 그림자는 최소화
- 색상 토큰
  - 배경 #FFFFFF / 사이드바 #F7F7F5 / 호버 #EFEFED
  - 본문 텍스트 #37352F / 보조 텍스트 #787774 / 테두리 #E9E9E7
  - 포인트 #2383E2
- 상태 배지 색상: 접수 회색, 확인 중 노랑, 처리 중 파랑, 답변 완료 보라, 처리 완료 초록, 보류 주황, 반려 빨강
- 레이아웃: 좌측 고정 사이드바(240px) + 본문(최대 폭 1200px)
- 데스크톱 우선, 1024px 이하에서는 사이드바를 접고, 모바일에서도 깨지지 않게 대응
- 아이콘은 Lucide 아이콘 사용

## 작업 규칙
- 한 번에 모든 기능을 만들지 말고 요청받은 단계만 구현한다.
- 작업 전에 구현 범위와 수정할 파일 목록을 먼저 보여주고, 승인받은 뒤 진행한다.
- 나는 Python 초보자다. 작업이 끝나면 다음을 한국어로 설명한다.
  1) 만들거나 수정한 파일과 각 파일의 역할
  2) 핵심 코드가 하는 일 (쉬운 말로)
  3) 설치 명령과 실행 방법, 확인할 URL
- 코드에는 초보자가 이해할 수 있도록 한국어 주석을 적당히 단다.
- 반복되는 화면 요소(상태 배지, 버튼, 카드, 빈 상태 등)는 templates/components/에 분리해 재사용한다.
- 비밀번호·메일 계정 등은 절대 코드에 직접 쓰지 않고 .env를 사용한다.
