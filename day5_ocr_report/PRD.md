# PRD.md — OCR 판정 보고서 앱

## 1. 목적
시험원이 스펙트럼 분석기 캡처 이미지를 하나씩 보고 손으로 옮겨 적던 측정값을 자동으로 읽고,
판정과 보고서 작성까지 한 번에 끝낸다. 목표: 이미지 20장 처리 + 보고서 작성 10분 이내.

## 2. 사용자
EMC·RF 시험원 (파이썬을 모르는 사용자도 버튼만으로 사용)

## 3. 입력
- 이미지: PNG/JPG 여러 장 (실습: images/img_01~20.png)
- 보고서 양식: report_template.docx
- 시험 정보: 문서번호, 시험일, 시험명, 시료명, 담당자, 검토자 (화면 입력)

## 4. 기능 요구사항
### M1. 이미지 데이터 추출
- [ ] 이미지 여러 장 업로드, 썸네일 표시
- [ ] [추출 시작] 버튼 → AI 비전으로 이미지별 JSON 추출
      {"file", "marker_freq", "freq_unit", "marker_power", "power_unit", "readable", "note"}
- [ ] 진행률 표시, 실패한 이미지는 "추출 실패"로 표시하고 계속 진행
- [ ] 결과 표 표시, 사용자가 표에서 값을 직접 고칠 수 있음

### M2. 판정
- [ ] 단위 통일: 주파수 → GHz, 전력 → µW (mW·nW도 변환)
- [ ] 계산: dBm = 10·log10(µW/1000), 측정값(dBµV/m) = dBm + 107 + CF, 마진 = Limit − 측정값
- [ ] 판정: 마진 ≥ 0 → PASS, 마진 < 0 → FAIL, 값이 None → 확인필요
- [ ] 선택 기준: 주파수 허용 범위(기본 2.4035~2.4060 GHz, 경계 포함) 밖이면 FAIL
- [ ] 사이드바에서 CF(기본 -51.5 dB), Limit(기본 54.0 dBµV/m), 주파수 범위, 주파수 기준 사용 여부 수정
- [ ] 요약: 총 건수, PASS, FAIL, 확인필요, 종합판정(FAIL 또는 확인필요가 하나라도 있으면 "부적합/확인필요")

### M3. 보고서
- [ ] docs/report_template.docx의 {{ }} 자리 채우기 (표의 {{r.*}} 행은 결과 건수만큼 복제)
- [ ] 서식(글꼴·표 테두리) 유지
- [ ] 특이사항({{remarks}})에 확인필요·FAIL 항목과 사유 자동 작성
- [ ] [보고서 다운로드] 버튼 (파일명: 문서번호_RE보고서.docx), 결과 CSV도 다운로드

## 5. 비기능 요구사항
- API 키는 화면 입력, 저장 금지
- 한 이미지 처리 실패가 전체를 멈추지 않음
- 판정 로직은 테스트로 검증 (tests/test_judge.py)

## 6. 완료 기준 (실습 이미지 기준)
- 20장 모두 결과 표에 나타난다
- img_17, img_18의 mW 값이 µW로 변환된다 (0.64183 mW → 641.83 µW)
- img_19(전력 가려짐), img_20(주파수 가려짐)은 "확인필요"
- 기본 기준(CF -51.5, Limit 54, 주파수 기준 사용)에서 PASS 11 / FAIL 7 / 확인필요 2
- 다운로드한 docx가 Word에서 오류 없이 열리고 측정 결과 표가 20행이다
